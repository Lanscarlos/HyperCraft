# HyperCraft 文件管理页重构 · 设计说明

面向执行的改造说明。**只改布局、交互和信息结构，不动现有配色主题与字体**——文中出现的
「强调色 / 警告色 / 危险色」一律复用项目里已有的 token。

设计稿：项目设计画布里标题为 **「文件管理（重排）」** 的画板（`Files2.dc.html`，状态 B，
1600×880）。画板用的是画布自带的绿色 token，实现时一律换成本项目现有的暖色 token，只参照
布局比例、行高、间距、控件层级与状态表达。

---

## 0. 背景

当前实现方向是对的：树 + 列表 + 编辑器同屏、点文件不跳页、编辑器底部有编码/换行符/行列/
同步状态、还有配置历史。问题集中在一处——**用「编辑模式」开关去解决布局问题**，由此派生出
两套行为不一致的树、宽度分配与注意力相反、以及列表列的隐式消失。

目标：**删掉模式开关，让布局跟随用户正在做的事自动变化。**

## 1. 范围

**改：** 顶栏与面包屑、目录树、文件列表、编辑器区（标签栏 / 正文 / 底部状态条）、批量操作、
空状态与错误态。

**不改：** 侧边导航、主题配色、字体、「配置历史」页本身、后端权限模型。

## 2. 核心决策

### 2.1 移除「编辑模式」开关

布局由「是否有文件打开」驱动，无需用户操作。

| 状态 | 触发 | 布局 |
| --- | --- | --- |
| A 浏览 | 没有打开任何文件 | 树 + 列表（列表铺满剩余宽度，显示完整列） |
| B 编辑 | 至少打开 1 个文件 | 树 + 列表（紧凑） + 编辑器（占剩余全部） |
| C 专注 | 用户手动折叠树和列表 | 编辑器几乎全宽，树和列表收成竖条 |

A → B 由「打开文件」自动触发，除动画位移外不做任何提示。C 保留折叠按钮，但不是必需路径。

### 2.2 树和列表的分工固定下来

- **目录树：只显示文件夹**，职责是导航。
- **文件列表：显示当前目录下的文件夹 + 文件**，职责是内容。

删掉「编辑模式下树里也列文件」。同一控件在两个模式下含义不同要学两遍；而且树里的文件名在
216px 宽度下大量截断，可读性反而更差。

## 3. 布局规格

外层 `grid`，间距 `14px`，容器内边距 `20px`。

- 状态 A：`树 216px | 文件列表 1fr`
- 状态 B：`树 216px | 列表 264px | 编辑器 minmax(0,1fr)`

栏之间可拖拽调宽，结果按实例持久化到 localStorage。树最小 180 / 最大 360；列表最小 220 /
最大 560；编辑器最小 640。窗口 < 1280px 时列表强制紧凑且不可拖宽；< 1024px 时列表改为抽屉式。

**关键约束：编辑器宽度必须 ≥ 780px 才算达标**（1600px 视口下）。780px 在 12.5px 等宽字体下
约 95 字符，正好放得下 Paper 默认配置最长的注释行。

## 4. 顶栏与面包屑

删掉页面标题区（大标题「文件」+ 说明文字），约省 100px 垂直空间。

顶栏高 56px，从左到右：返回上级（图标，根目录禁用）、面包屑、当前目录统计 chip、
（右侧）搜索框（⌘F/Ctrl+F 聚焦）、上传、新建（下拉：文件/文件夹）、刷新、更多。

面包屑：每段可点击；`/` 分隔，等宽字体；过长时从中间省略，保留首段和末两段；**末段之后有一块
可点击的空白区**，点击后整条切换为可编辑 `input`（完整路径纯文本），`Enter` 跳转、`Esc` 还原、
路径不存在时行内报错且不跳转、支持粘贴。

**工具栏按钮在所有状态下保持同一组、同一顺序、同一形态。**

## 5. 目录树

卡片式容器，内边距 8px，行高 30px。根节点「实例根目录」默认展开。只渲染文件夹；展开箭头仅在
确有子目录时显示。当前目录高亮（强调色底 + 强调色文字 + 加粗）。展开状态按实例持久化。
删掉「筛选已展开的目录」输入框，目录过滤由顶栏搜索覆盖。

## 6. 文件列表

### 6.1 两种密度

列表顶部 36px 的头：左边「当前目录」，右边 `紧凑 / 详情` 分段控件。

| 模式 | 行高 | 列 |
| --- | --- | --- |
| 紧凑 | 34px | 图标 + 名称 + 大小 |
| 详情 | 40px | 图标 + 名称 + 大小 + 修改时间 + 操作 |

状态 A 默认「详情」，状态 B 默认「紧凑」；用户手动切换后覆盖自动默认，按实例持久化。
**列的增减必须是用户可见的选择，不能作为宽度变化的副作用发生。**

### 6.2 行

文件夹排在文件前面，各自按名称升序；列头可切换排序字段与方向。图标按扩展名区分，靠颜色区分
类别。名称超长 ellipsis + `title` 给完整名。修改时间 7 天内相对、超过则 `YYYY/MM/DD HH:mm`，
同一列格式统一，`title` 始终给完整时间戳。单击 = 选中并打开（文件）/ 进入（文件夹）；
双击不额外定义。

### 6.3 行操作改为 hover 显示

默认行尾只显示大小（紧凑）或大小 + 时间（详情）。hover / 键盘聚焦时出现「下载」和 `⋯`
下拉（重命名、复制路径、移动到…、在新标签打开、**删除**（红色、末项、有分隔线））。

删除必须二次确认：文件用普通确认弹窗；文件夹要求输入文件夹名才能提交；`world`、`plugins`、
`libraries` 等关键目录额外加一条警告文案。

### 6.4 多选与批量操作

复选框不常驻，hover 或已选中时替换行首图标。`Shift+点击` 选区间，`⌘/Ctrl+点击` 加选。
一旦有选中项，36px 的头替换为批量操作条：`已选 3 项 · 12.4 MB` + 下载 / 移动到… / 删除 +
右侧「取消选择」。批量删除同样走确认，文案列出前 3 个名字 + `等 N 项`。

### 6.5 空状态与错误态

空目录、搜索无结果、读取失败（行内错误卡片 + 重试，不用全屏错误页）、拖拽上传高亮。

## 7. 编辑器区

### 7.1 标签栏（高 40px）

多标签横向排列：类型图标 + 文件名（等宽）+ 未保存圆点（警告色）+ 关闭 `×`。关闭未保存标签弹
确认。中键关闭；`⌘/Ctrl+W` 关闭当前标签。超出宽度横向滚动不换行；上限 12 个，超出按 LRU 关闭
最早且已保存的标签。标签右键菜单：关闭、关闭其他、关闭右侧、复制路径。

标签栏右侧：`配置历史`（从底部按钮条挪上来）、`分屏对照`（最多 2 栏，各自独立标签栏）、
查找替换、`⋯`（格式化、切换换行、只读模式、在文件列表中定位、快捷键）。

### 7.2 正文

行号槽宽 52px，右侧 1px 分隔线，背景比正文略深。**改动行标记**：与上次保存的版本逐行比对，
改动行的行号底色用警告色浅底 + 行内容左侧 2px 警告色竖条；悬停改动行的行号出现「还原此行」。
语法高亮：YAML、JSON、Properties、TOML、纯文本、日志（日志按 INFO/WARN/ERROR 着色）。
保存后清空改动标记。光标位置、滚动位置按「实例 + 文件路径」缓存。

### 7.3 底部状态条（高 38px）

左：`YAML · UTF-8 · LF · 行 18，列 24`（等宽）+ `2 行已改` 警告色 chip（无改动时不显示）。
右：`1 KB · 44 行` → `还原`（次级，无改动时禁用）→ `保存`（主按钮，无改动时禁用）。
删掉「关闭」按钮和「Ctrl/⌘+S 也能保存」那行文字（改成保存按钮的 tooltip）。
「撤销修改」改名「还原」，需二次确认。

### 7.4 保存与冲突

`⌘/Ctrl+S` 保存当前标签。保存带上打开时拿到的 mtime；不一致时三选一：用我的覆盖 /
放弃我的改动重新加载 / 并排查看差异。文件在面板外被修改时，编辑器顶部出现提示条
`磁盘上的文件已变化` + 重新加载 / 保留我的版本；当前无改动则静默重载。
服务器运行中保存配置类文件（`server.properties`、`bukkit.yml`、`spigot.yml`、`paper-*.yml`、
`plugins/**/config.yml`），保存成功后 toast `已保存 · 需重启服务器后生效` + `重启` 按钮。

### 7.5 不进编辑器的文件

超过编辑上限的文本文件、二进制文件（`.jar`、`.db`、图片、压缩包）不进编辑器，显示文件信息
卡片 + `下载`；图片显示预览。

## 8. 快捷键

| 键 | 行为 |
| --- | --- |
| `⌘/Ctrl + F` | 焦点在列表 → 聚焦目录搜索；焦点在编辑器 → 编辑器内查找 |
| `⌘/Ctrl + S` | 保存当前标签 |
| `⌘/Ctrl + W` | 关闭当前标签 |
| `↑ ↓` | 在文件列表中移动选择 |
| `Enter` | 打开选中项 |
| `Backspace` | 返回上级目录 |
| `Shift/⌘Ctrl + 点击` | 区间选 / 加选 |
| `Esc` | 退出路径编辑 / 取消多选 / 关闭查找框 |

全部快捷键在 `⋯` 菜单里提供一个「快捷键」弹窗。

## 9. 后端确认结果（读代码得出，2026-09-14）

| 项 | 结论 | 处置 |
| --- | --- | --- |
| 文件夹打包下载 | **没有** `files/archive` 之类的路由（`internal/api/routes.go:334-340`） | 去掉文件夹下载与 `下载 zip`；批量下载沿用「逐个下载文件」 |
| 外部变更 WebSocket | **没有**，`internal/api/ws.go` 只推控制台 history/line/state | 降级为「编辑器在前台时每 10s 列一次父目录比对 mtime」 |
| 读接口 mtime / 条件写 | **没有**，`fileContentResponse` 只有 path+content，`writeFileRequest` 只有 path+content | 降级为保存前再列一次父目录做客户端比对；**有竞态**，PR 中标注 |
| 实例配额 | **没有**任何实例级配额 API | 去掉 §5 底部的配额进度条 |
| 「仅查看前 2 MB」 | 没有 range 读；后端上限是 `maxEditableBytes`（1 MiB），`entry.editable` 已在拦 | 只保留信息卡片 + 下载完整文件 |
| 编码切换 | 读接口不返回检测到的编码 | 状态条固定显示 UTF-8，不提供切换 |
| 复制（duplicate） | 没有服务端复制接口；走浏览器等于把 300 MB jar 拉一遍再传回去 | 从 `⋯` 菜单里去掉 |
| 移动到… | `POST files/rename` 的 from/to 都是相对实例根的完整路径，跨目录 rename 即移动 | 正常实现 |
| 格式化 | 没有 YAML 格式化器，且不为此引依赖 | 只对 JSON 可用，其余禁用并在 tooltip 里说明 |
